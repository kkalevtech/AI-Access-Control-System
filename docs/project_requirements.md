# OOP in Python Project Requirements (11th Grade – AI Programming)

## Project Package Overview

**Subject:** Object-Oriented Programming in Python
<br>
**Grade:** 11th Grade
<br>
**Profile:** AI Programming

## Final Product

* a Python application (GUI)
* a database
* file handling functionality
* an ML/AI component
* a final presentation

---

# Mandatory Requirements

## 1. OOP Structure

The project must contain at least **6 classes**, including:

* data model classes
* AI/ML logic class
* controller/manager class
* events/observer class
* file handling class
* database handling class

---

## 2. Communication Between Objects

Objects must interact with each other.

Required:

* object collaboration
* Observer Pattern (event-based communication)
* at least **2 listeners for one event**

---

## 3. Delegates / Events (Python Style)

Required:

* callback functions
* event dispatcher
* custom event arguments (custom event classes)

---

## 4. LINQ Equivalent in Python

Use Python tools for data processing such as:

* list comprehensions
* `map()`
* `filter()`
* `reduce()`
* `sorted()`
* `groupby()`
* data analysis operations

---

## 5. File Handling

The project must support:

* logs
* reading/writing `.json`
* reading/writing `.csv`

---

## 6. Exception Handling

Required:

* `try/except`
* custom exceptions
* error handling for the AI model

---

## 7. Database

Use:

* SQLite

Requirements:

* minimum **3 tables**
* full CRUD operations (Create, Read, Update, Delete)

---

## 8. AI Component (Mandatory)

The project must include a simple AI/ML component such as:

* classification
* regression
* rule-based AI
* data analysis

---

## 9. Final Presentation

The presentation must include:

* demonstration of the AI component
* explanation of how the model works
* limitations and possible errors

---

# Anti-AI Requirements

## Own Data

The project must contain at least **30 custom records** created by the students.

---

## AI Development Journal

Document:

* used libraries
* what was understood
* what was changed and adapted

---

## Algorithm Explanation

Students must be able to explain:

* how the algorithm works
* why it was chosen

---

## Live Change During Defense

During project defense, students may be asked to make a live modification to prove understanding.

---

## No Copy-Paste Models

Ready-made AI models are not allowed without adaptation.

The solution must be understood, modified, and explained by the students.
